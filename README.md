# Realign Yoga Therapy — landing page

A single-file marketing landing page for a one-on-one yoga therapy service aimed
at people who work at a desk all day (back pain, neck pain, weight-loss support,
blood-sugar / metabolic health).

## Files

- `index.html` — the entire site: HTML, CSS, and a small amount of JavaScript in
  one file. No build step, no dependencies to install.

## Running locally

Open `index.html` in any web browser (double-click it), or serve the folder with
any static file server.

## Deployment

Hosted with **GitHub Pages** from the `main` branch, root folder.
Live at: https://cosmicis65.github.io/landing-page-yoga/

## Booking

The booking section embeds a Calendly inline widget
(`calendly.com/cosmicis65/30min`). To change it, edit the `data-url` on the
`#calendly-embed` element in `index.html` and keep the `?...` theme parameters.
